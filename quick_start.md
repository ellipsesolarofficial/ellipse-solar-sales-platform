## 🎯 Key Features You'll Use

### Real-Time Panel Count
As you change system capacity or panel wattage, the platform automatically shows how many panels are needed.

### Smart Meter Logic
- Select "Yes" if customer already has smart meter
- Net meter cost automatically becomes ₹0

### Site Type Adjustments
- **Standard**: Normal pricing
- **Special**: +20% wire, +30% labour
- **Ground**: +50% labour

---

## 💡 Pro Tips

1. **Always use "Calculate Estimate" first** - Preview before generating PDF
2. **Panel capacity affects count** - 600W = fewer panels than 550W
3. **Inverter auto-matches system** - But can be adjusted if needed
4. **Smart meter check saves ₹5,015** - Always ask customer
5. **Special site = higher cost** - Warn customer beforehand

## ❓ Troubleshooting

### Problem: Panel count not updating
**Solution**: Make sure both System Capacity and Panel Capacity are filled

### Problem: PDF not downloading
**Solution**: Check browser allows downloads. Click "Download PDF" button again

### Problem: WhatsApp not opening
**Solution**: Verify phone number format: 919876543210 (no spaces/dashes)

### Problem: Wrong final amount
**Solution**: Click "Calculate Estimate" to see breakdown before PDF generation
