# Ellipse Solar - Enhanced Pricing Structure

## Overview
The pricing system has been completely overhauled to match your detailed Bill of Materials (BOM) with accurate GST calculations and component-level pricing.

## Pricing Components

### 1. Solar Panels
Three panel options available with different specifications:

| Panel Type | Wattage | Price/Watt | GST | Efficiency | Warranty |
|------------|---------|------------|-----|------------|----------|
| TOPCON-600W+ | 600W | ₹24.65 | 12% | 23% | 25 years |
| Monocrystalline | 550W | ₹26.00 | 12% | 22% | 25 years |
| Bifacial | 580W | ₹28.00 | 12% | 24% | 30 years |

**Calculation:**
- Panel Count = System Size (kW) × 1000 / Panel Wattage
- Base Cost = Price per Watt × System Size (kW) × 1000
- GST = Base Cost × 12%
- Total Panel Cost = Base Cost + GST

**Example for 5kW System with TOPCON-600W+:**
- Panels needed: 5000W / 600W = 9 panels
- Base Cost: ₹24.65 × 5000 = ₹123,250
- GST: ₹123,250 × 12% = ₹14,790
- Total: ₹138,040

### 5. Government Subsidy
- Subsidy Rate: ₹18,000 per kW
- Maximum Eligible: 3 kW
- Calculation: Min(System Size, 3) × ₹18,000

**Examples:**
- 3 kW system: 3 × ₹18,000 = ₹54,000
- 5 kW system: 3 × ₹18,000 = ₹54,000 (capped)
- 10 kW system: 3 × ₹18,000 = ₹54,000 (capped)

## GST Structure Summary

Different components have different GST rates:

| Category | GST Rate | Items |
|----------|----------|-------|
| Solar Panels | 12% | All panel types |
| Inverters | 5% | All inverter types |
| Electrical Components | 18% | ACDB, DCDB, Wires, Meters, etc. |
| Structure Components | 18% | Legs, Rafters, Perlings |
| Black Pipe | 5% | Conduit pipes |
| Additional Charges | 0% | Transportation, Labour, DISCOM |

## Usage in the Platform

1. **Select Panel Type**: Choose from TOPCON, Monocrystalline, or Bifacial
2. **Select Inverter**: Choose from POLYCAB, FESTON, or Hybrid
3. **Enter System Size**: Input desired capacity in kW
4. **Automatic Calculation**: System calculates:
   - Exact panel count needed
   - Component requirements
   - GST for each category
   - Total project cost
   - Subsidy eligibility
   - Final payable amount

## Price Updates

To update prices, edit `public/rates.json`:

```json
{
  "solarPanels": {
    "topcon600w": {
      "pricePerWatt": 24.65,  // Update this value
      "wattage": 600,
      "gstRate": 0.12
    }
  }
}
```

The system will automatically recalculate all quotations with new rates.
